# People-shelf privacy policy

This public repository intentionally starts without named collaborator files.
Create one only when an explicit, stable workflow preference materially helps
future work and cannot be represented more generally in `AGENTS.md`.

Allowed material is limited to concise, work-relevant preferences the person
has explicitly stated, such as verification style or preferred handoff shape.
Review it for continued usefulness and remove stale entries.

Never store personal biography, contacts, relationship details, inferred
traits, exact private quotes, conversation transcripts, browser profiles,
screenshots of logged-in state, wallet/FID/inbox/installation identifiers,
notification URLs or tokens, private keys, signatures, credentials, message
content, attachments, pairing URIs, raw production payloads/logs, or hidden
reasoning.

Treat repository visibility as public even if hosting settings later change.
